# Claude build instructions

Read these files before building:

1. `AGENT.md` in the parent AI Engineer workspace
2. This project’s `README.md`
3. `docs/BUILD_PLAN.md`

You are allowed to inspect files, propose architecture, write code, run tests, debug failures, and review changes. Keep the work reviewable and explainable. Do not claim completion without showing the relevant evidence.

For each build session:

- state the goal and acceptance criteria;
- identify the smallest safe vertical slice;
- implement only that slice;
- run or add tests;
- summarize changed files and known limitations;
- update the parent progress log when the session produces meaningful evidence.

Do not add external credentials, autonomous deployment, unrestricted shell execution, or hidden data collection without an explicit decision and a documented safety review.
